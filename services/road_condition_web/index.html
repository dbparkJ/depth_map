왜 손상 후보로 표시했는지

실험 임계값 · 현장 검수 필요
  1. 도로면만 남김수집점에서 도로 통로를 찾고, 기준면에서 지나치게 높은·낮은 비노면 점은 후보 판정에서 제외합니다.
  2. 정상 도로면 추정주변의 안정된 점으로 완만한 기준 표면을 만들고 실제 높이와 비교합니다.
  3. 형상과 크기 확인연속된 함몰은 포트홀, 바퀴 진행 방향의 골은 러팅, 연속된 돌출은 융기 후보로 구분합니다.
  4. 사람이 최종 확인깊이·면적·점 지지율과 지도 마스크를 함께 보고 RGB·실측으로 승인합니다.
