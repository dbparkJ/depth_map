# 2026 공공 도로보수 예산 근거 체크포인트

## 결론

화면의 예산값을 `실제 견적`으로 표시하지 않는다. 2026년 하반기 국토교통부 표준시장단가에서
현재 결함 형상으로 계산할 수 있는 공종만 합산한 `공식 기준 중 계산 가능한 금액`과, 현장별로
별도 산출해야 하는 항목을 나누어 보여준다.

나라장터 공고 총액은 계약 규모를 이해하기 위한 참고 사례로만 사용한다. 여러 공종·교통관리·
상시대기가 섞인 총액을 단순히 보수 면적으로 나누어 포트홀 ㎡당 단가로 쓰지 않는다.

## 공식 단가 확인값

적용 기준일은 국토교통부 공고 제2026-652호가 공고된 `2026-05-08`이다.

| 코드 | 2026년 하반기 표준시장단가 | 단가 | 중요한 제외 항목 |
|---|---|---:|---|
| DC221.10000 | 아스팔트포장 깨기, T<30 cm | 13,927원/㎥ | 적재·운반·폐기물 처리 |
| DC221.20000 | 포장절단/아스팔트 | 2,617원/m | 포장두께 20 cm 이하 기준 |
| LC211.00000 | 텍코팅 인력식 1회 | 102원/㎡ | 코팅 재료비 |
| LC401.00750 | 아스콘 표층·중간층 소규모포설, 7.5 cm 이하 | 7,960원/㎡ | 아스콘 재료비·장비 운반 |

포트홀 표층 보수의 표시 단가는 다음 `부분 금액`만 더한다.

```text
13,927원/㎥ × 가정 두께 0.05m = 696.35원/㎡  (깨기)
102원/㎡                                      (인력식 텍코팅 작업)
7,960원/㎡                                    (소규모 표층 포설·다짐 작업)
합계 8,758원/㎡                               (원 단위 반올림)
```

러팅 표층 덧씌우기는 깨기를 제외한 `102 + 7,960 = 8,062원/㎡`만 계산한다. 융기부의
절삭·연삭은 선택한 공식 항목만으로 공법을 특정할 수 없어 금액을 `N/A`로 둔다.

이 값은 재료·절단 경계·운반·폐기·교통통제·간접비·부가세가 빠진 전체 보수비가 아니다.

## 2026 표준품셈에서 확인한 현장 조건

- 소파보수(표층) 일당 시공량은 보수점이 밀집한 A-Type 400㎡, 부분 산재 B-Type 140㎡,
  산발 C-Type 50㎡다.
- 보수점의 분산 정도, 이동·대기, 개소별 평균 면적에 따라 같은 면적도 생산성이 달라진다.
- 교통통제와 안전처리 인력·시설은 현장 교통상황, 통제 시간과 범위에 따라 별도 계상한다.

따라서 작은 결함 여러 개를 서로 먼 곳에서 보수하는 비용을 면적 하나만으로 확정할 수 없다.

## 구현

- catalog: `maintenance_catalogs/kr-molit-2026h2-reference.yaml`
- 기본 API catalog를 위 2026 reference catalog로 변경했다.
- 완료된 route의 선택 tile은 read-only
  `GET /api/v1/route-datasets/budget-report`로 같은 catalog와 후보를 계산한다. 따라서 POST가
  차단된 외부 공개 화면에서도 예산 검토 자료를 조회할 수 있다.
- 결과는 다음을 분리한다.
  - `priced_known_components_lower_bound`: 공식 항목 중 계산 가능한 부분 합계
  - `full_project_estimate`: `N/A`
  - `unpriced_components`: 재료·절단·운반·폐기·교통통제·장비 이동·현장설계·간접비·VAT
  - `public_project_context`: 나라장터 총액과 혼합 범위, 단가 전용 금지 표시
  - `procurement_checklist`: 발주 전 현장 산출 항목
- 융기부처럼 선택한 공식 공종으로 가격을 만들 수 없는 후보는 0원으로 가장하지 않고
  `unpriced_candidate`로 분리한다.
- 웹은 route tile을 열 때 계산 가능한 공종 부분합 하한, 예산 내 후보, 보류 후보,
  단가 미산정 후보와 전체 비용 N/A 사유를 자동 표시한다.

## 알려진 제한

- 발주기관이 승인한 설계내역서나 업체 견적이 아니다.
- 현재 결함 mask는 현장 확정 물량이 아니다.

  제시하지 않는다.
